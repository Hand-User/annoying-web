# 🚨 The World's Most Annoying Website

A satirical, interactive web design experiment showcasing dark patterns, uncooperative UI physics, and user frustration heuristics. Built entirely with vanilla HTML5, CSS3, and the Web Audio API (zero external dependencies).

## 🎯 Features

* **Authentic Dark Patterns:**
  * **Aggressive Cookie Wall:** Forces compliance with 9,482 imaginary tracking partners.
  * **Cumulative Layout Shift (CLS):** Dynamic shifting banners that push content right before the user clicks.
  * **Deceptive Download Traps:** Multiple prominent `.exe` buttons designed to mislead users away from the actual link.
  * **Unclosable Floating Video:** Corner video player that relocates across the screen when attempting to close it.
  * **Endless Pagination:** High-effort, zero-reward article progression (*"Page 1 of 49"*).

* **Custom Browser Audio Engine (Web Audio API):**
  * Synthesized fast-tempo carnival organ jingle.
  * High-volume stadium airhorns and cartoon sound effects.
  * Runaway **Mute** button that teleports whenever the cursor approaches.

* **Clean Architecture:**
  * Zero npm dependencies, frameworks, or external CDNs.
  * 100% self-contained single-page application.
  * Instant load times on desktop and mobile browsers.

## 🚀 How to Run Locally

Simply clone the repository and open `index.html` in any browser:

```bash
git clone https://github.com/<your-username>/annoying-website.git
cd annoying-website
start index.html
```

Or run with Node.js:
```bash
node server.js
```
Navigate to `http://localhost:3000`.
